# Practice-03: Python Functions, Lambda, Classes, Inheritance

Данный репозиторий содержит примеры кода для изучения основ Python по темам:

- **functions** — определение функций, аргументы, возвращаемые значения, `*args` и `**kwargs`.
- **lambda** — анонимные функции и их применение с `map`, `filter`, `sorted`.
- **classes** — создание классов, конструктор `__init__`, методы, переменные класса и экземпляра.
- **inheritance** — базовое наследование, `super()`, переопределение методов, множественное наследование.

Каждый файл содержит 5 наглядных примеров с комментариями. Используйте их для повторения или обучения.
