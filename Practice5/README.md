# Practice 5: Python Regular Expressions (RegEx)

## Описание
Данная работа посвящена изучению регулярных выражений в Python с использованием модуля `re`. В ходе выполнения задания был разработан скрипт `receipt_parser.py`, который анализирует текстовый файл `raw.txt`, содержащий данные чека, и извлекает из него:
- дату и время покупки,
- список товаров с ценами,
- общую сумму,
- способ оплаты.

Результат выводится в формате JSON.
